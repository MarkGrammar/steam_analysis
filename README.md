# Steam Games Analysis Projects

This repository contains two beginner-level data analysis projects using a sample Steam dataset. Both projects showcase end-to-end analysis using SQL, Python, and Tableau.

---

## Projects

### 1. [Free vs Paid Game Analysis](steam_free_vs_paid/)
Compare player behavior and user satisfaction between free and paid Steam games.

-Metrics: Average rating, daily players, number of games
-Tools: SQL, Python (pandas, matplotlib), Tableau
-[Dashboard on Tableau Public](https://public.tableau.com/app/profile/yusuf.deniz.demirci/vizzes)

---

### 2. [Genre-based Analysis](steam_genre_analysis/)
Explore the popularity and user ratings across different game genres.

-Metrics: Genre-wise average rating & players
-Tools: SQL, Python (scatter plots & bar charts), Tableau
-[Dashboard on Tableau Public](hhttps://public.tableau.com/app/profile/yusuf.deniz.demirci/vizzes)
